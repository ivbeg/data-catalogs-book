# Stable Addresses for Links

The site has not yet been published on a permanent domain: the build settings contain a placeholder address. Until a domain is chosen, chapters are not linked to from outside.

Once there is a domain, a chapter's path is not changed silently. If a chapter is renamed, a redirect is set up from the old address. Old paths about APIs and identifiers already lead to the new chapters.

The list of paths for the registry knowledge base is maintained together with the site, separately from the text for readers.

The English edition lives under the `/en/` path prefix and follows the same rule: its paths mirror the Russian ones.
