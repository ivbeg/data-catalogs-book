# Stable Addresses for Links

The book's permanent address is [datacatalogs.begtin.tech](https://datacatalogs.begtin.tech/). You can link to chapters and sections from outside: their addresses do not change silently.

## Addresses of the book

| Edition | Site | PDF |
|---------|------|-----|
| English | [datacatalogs.begtin.tech/en/](https://datacatalogs.begtin.tech/en/) | [data-catalogs-book-en.pdf](https://datacatalogs.begtin.tech/data-catalogs-book-en.pdf) |
| Russian (original) | [datacatalogs.begtin.tech](https://datacatalogs.begtin.tech/) | [data-catalogs-book.pdf](https://datacatalogs.begtin.tech/data-catalogs-book.pdf) |

An English chapter has the same path as the Russian one with the `/en/` prefix: for example, `https://datacatalogs.begtin.tech/en/types/classification/` and `https://datacatalogs.begtin.tech/types/classification/`. A full chapter address is the domain plus the path, with a trailing slash.

The book's former address `ivbeg.github.io/data-catalogs-book/` redirects to the new domain together with the chapter path, so old links keep working. How to cite the book as a whole is described in [About this edition](../index.md#about-this-edition).

## How addresses stay stable

A chapter's path is not changed silently. If a chapter is renamed, a redirect is set up from the old address. Old paths about APIs and identifiers already lead to the new chapters.

The list of paths for the registry knowledge base is maintained together with the site, separately from the text for readers.
