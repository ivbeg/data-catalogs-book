# Стабильные пути сайта

Список для тех, кто ссылается на книгу из базы знаний реестра. Это не глава для читателя: постоянного домена ещё нет (`url` в `docusaurus.config.ts` — заглушка). Когда домен появится, полный адрес — домен плюс путь, со слэшем в конце. Путь не меняют без перенаправления со старого.

Якоря заголовков Docusaurus строит из текста заголовка. На якорь ссылаются, только если заголовок больше не будут переименовывать.

## С чего начать

| О чём речь | Путь |
|------------|------|
| О книге | `/` |
| Маршрутная карта выбора | `/choice/route-map/` |
| Карта возможностей | `/features/capability-map/` |
| Когда портал не нужен | `/beyond-portals/when-portal-not-needed/` |
