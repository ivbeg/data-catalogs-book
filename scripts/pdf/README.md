# PDF-версия книги

PDF собирается из готового сайта, а не из Markdown: так в нём те же схемы Mermaid, таблицы, врезки и ссылки, что и на сайте.

```bash
npm run build      # сайт в build/
npm run pdf        # PDF в build/data-catalogs-book.pdf
npm run build:pdf  # обе команды подряд
```

На GitHub Actions PDF собирается при каждой публикации сайта (`.github/workflows/deploy-pages.yml`) и лежит рядом с ним: `https://datacatalogs.begtin.tech/data-catalogs-book.pdf`.

## Что нужно

- Node.js 20 и новее, зависимости из `npm ci` (`playwright-core`, `pdf-lib`).
- Google Chrome 131 и новее: в нём работают номера страниц и колонтитулы CSS. Браузер Playwright не скачивается, используется установленный Chrome.
  - Другой путь к браузеру — переменная `CHROME_PATH`.
  - Chromium из Playwright — `npx playwright install chromium` и `PDF_BROWSER_CHANNEL=chromium`.
- Шрифты PT Serif, PT Sans и PT Mono. В macOS они есть, в Ubuntu — пакет `fonts-paratype`. Без них подставятся Georgia, Arial и Menlo, вёрстка поедет.

## Как устроено

1. `build-pdf.mjs` поднимает локальный сервер над `build/` и идёт по ссылкам «Следующая страница», начиная с главной. Порядок совпадает с боковым меню. Страницы категорий становятся титулами частей; если обход перескакивает категорию (как у главной с `pagination_next`), она восстанавливается по хлебным крошкам.
2. Каждая страница открывается в Chrome. Скрипт ждёт гидратации и схем Mermaid и забирает только текст главы — без меню, оглавления и кнопок. Число схем сверяется с исходниками в `docs/`: если отрисованы не все, сборка падает.
3. Главы склеиваются в одну HTML-книгу: обложка, выходные данные, содержание, части, главы. Глава верхнего уровня после частей (файл в корне `docs/`, как `13-about-the-author.md`) стоит в конце книги отдельно, а не внутри последней части. Якоря получают префикс главы, ссылки между главами становятся внутренними ссылками PDF, ссылки на прочие страницы сайта — абсолютными адресами.
4. Chrome печатает книгу дважды. После первого прохода из PDF читаются номера страниц глав, во втором они стоят в содержании.
5. `pdf-lib` добавляет закладки (части → главы → разделы второго уровня) и метаданные из `CITATION.cff`: название, автор, аннотация, ключевые слова, язык.

Название, автор, лицензия и адреса берутся из `CITATION.cff`, подзаголовок и «Редакция …» — с главной страницы книги.

## Что настраивать

- Оформление — `print.css`: формат страницы (`@page { size: A4 }`), поля, шрифты, таблицы, код.
- Интерактивные компоненты — `INTERACTIVE_REPLACEMENTS` в `build-pdf.mjs`. Сейчас там маршрутная карта: в PDF вместо неё пояснение со ссылкой на сайт. Новый интерактивный компонент нужно добавить туда же, иначе в PDF попадут его кнопки.
- Параметры: `--out путь.pdf`, `--build-dir`, `--concurrency 4` (сколько страниц открывать одновременно), `--html путь.html` — сохранить собранную HTML-книгу для отладки вёрстки.
- `SOURCE_DATE_EPOCH` — дата сборки на обороте титула и в метаданных.
