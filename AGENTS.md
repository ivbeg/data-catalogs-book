# Каталоги данных — книга на Docusaurus

Самостоятельная книга о публичных каталогах данных: что это, какие бывают, какие у них возможности, как выбрать функции и платформу и как публиковать данные, в том числе без портала.

- Принципы проекта: `.cursor/rules/book-principles.mdc`
- Шаблоны и оформление глав: `.cursor/rules/chapter-writing.mdc`
- План работ и статус задач: `PLAN.md`

Тексты лежат в `docs/`. Части и главы упорядочены числовыми префиксами папок и файлов, URL строится без префиксов (`docs/04-features/02-metadata-export.md` → `/features/metadata-export/`).

Интерактивная маршрутная карта — `src/components/RouteMap/` (правила в `model.ts`). Переопределённый компонент Mermaid в `src/theme/Mermaid/` рендерит схемы по очереди: без этого на странице с несколькими схемами при первой загрузке видна только первая.

```bash
npm start            # разработка
npx tsc --noEmit     # проверка типов
npm run build        # сборка, падает на битых ссылках
npm run pdf          # PDF из готовой сборки: build/data-catalogs-book.pdf (scripts/pdf/README.md)
npm run pdf:all      # оба PDF (русский и английский) в корне обеих языковых версий сайта
```

## Английская версия

Основной язык — русский (`docs/`), английский перевод лежит в `i18n/en/docusaurus-plugin-content-docs/current/` с теми же путями файлов и выходит по адресу `/en/`. Переключатель языков — в меню, ссылки на PDF обоих языков — на главной и в подвале.

- В английском файле те же заголовки `##`–`######`, в том же порядке и количестве, что в русском. Ссылки на разделы сначала пишутся с русскими якорями, потом `node scripts/i18n/remap-anchors.mjs` заменяет их на английские по порядку заголовков (`--check` — только проверка).
- Подписи меню, частей и подвала — `i18n/en/*.json`.
- Стиль перевода: британское написание (licence, organisation), но catalog; даты «14 October 2026»; русские источники помечены «(in Russian)»; значения во frontmatter с «: » — в кавычках.

Интерактивные компоненты в PDF заменяются пояснением со ссылкой на сайт: список — `INTERACTIVE_REPLACEMENTS` в `scripts/pdf/build-pdf.mjs`. Новый интерактивный компонент нужно добавить туда же.
