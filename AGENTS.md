# Каталоги данных — книга на Docusaurus

Самостоятельная книга о публичных каталогах данных: что это, какие бывают, какие у них возможности, как выбрать функции и платформу и как публиковать данные, в том числе без портала.

- Принципы проекта: `.cursor/rules/book-principles.mdc`
- Шаблоны и оформление глав: `.cursor/rules/chapter-writing.mdc`
- План работ и статус задач: `PLAN.md`

Тексты лежат в `docs/`. Части и главы упорядочены числовыми префиксами папок и файлов, URL строится без префиксов (`docs/04-features/02-metadata-export.md` → `/features/metadata-export/`).

Интерактивная маршрутная карта — `src/components/RouteMap/` (правила в `model.ts`). Переопределённый компонент Mermaid в `src/theme/Mermaid/` рендерит схемы по очереди: без этого на странице с несколькими схемами при первой загрузке видна только первая.

```bash
npm start            # разработка
npx tsc --noEmit     # проверка типов
npm run build        # сборка, падает на битых ссылках
```
