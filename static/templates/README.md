# Название набора данных

Коротко: что это за данные, за какой период и какую территорию, кто их собрал.

## Как пользоваться

- Файл `data/example.csv` — таблица.
- Описание колонок — в `datapackage.json`.
- Лицензия — в файле `LICENSE` (укажите SPDX-идентификатор, например CC-BY-4.0).

## Как обновляется

Кто обновляет, как часто, откуда берутся новые данные.

## Как сослаться

См. `CITATION.cff`. DOI в этот файл и в поле `identifier` разметки страницы добавляют после того, как номер выдан. Пока его нет, эти поля не заполняют.

## Контакт

Имя и адрес почты ответственного.
