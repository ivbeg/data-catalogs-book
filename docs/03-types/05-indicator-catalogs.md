# Каталоги показателей

Каталог показателей отдаёт статистические ряды и таблицы с разрезами: время, территория, пол, отрасль. Человек не скачивает «файл за 2019 год», а выбирает разрез. Программа должна уметь то же самое запросом.

По выгрузке реестра от 9 октября 2026 года (выпуск 1.26.0 от 6 октября) таких каталогов около 3,2 тысячи.

## Кто создаёт и что публикует

Национальные статистические службы и центральные банки. Международные организации: Евростат, ОЭСР, Всемирный банк, МВФ, ООН. Регионы и города — реже, в реестре около 250 местных витрин.

Публикуют макроэкономику, демографию, социальную статистику, показатели целей устойчивого развития.

Статистику публикуют на одной из трёх ступеней. На первой это документы: сборники и бюллетени в PDF, из которых ряд за десять лет собирают руками. На второй — таблицы: Excel на сайте или конструктор, который строит таблицу по запросу и даёт её скачать. На третьей данные первичны, а сайт с графиками — одна из витрин: вся база выгружается целиком, у каждого показателя есть адрес в API, справочники общие. Каталог показателей в смысле этой главы начинается со второй ступени, а пользы от него много только на третьей.

## Стандарты

Обмен показателями — SDMX. Для веб-таблиц рядом используют JSON-stat и PC-Axis. Международным организациям нужна точка SDMX. Сайт с графиком для обмена рядами не подходит. Описание показателя — методика, единица измерения, разрывы ряда — хранят отдельно от чисел. Без него ряд нельзя сравнивать между годами.

## Платформы

Самописных витрин 42%, больше, чем у любого крупного типа. И программный доступ есть только у 38% каталогов показателей — худший показатель среди крупных типов. Конструктор таблицы в браузере без API оставляет данные на сайте.

Готовые платформы: Swing (около 200), Knoema (около 125), национальные страницы данных по образцу МВФ (около 120), PxWeb (около 110, среди них Statbank Denmark), OpenSDG (около 70, это в первую очередь витрина целей устойчивого развития), .Stat Suite (около 40: ОЭСР, ФАО, МОТ, статистические службы Австралии, Новой Зеландии, Италии, Швейцарии). WordPress и Drupal в этой группе — обычные сайты со страницами показателей, не платформы SDMX.

PxWeb и .Stat отдают SDMX из ядра. OpenSDG хорош как понятная витрина и слаб как единственный канал обмена.

Тиражируемого ПО для статистики мало, по сути три продукта:

- **PxWeb** разработало Статистическое управление Швеции. На нём работают службы скандинавских стран и десятки других. Последний выпуск — 2025.v1, февраль 2025 года.
- **.Stat Suite** — открытая платформа сообщества SIS-CC, которое ведёт ОЭСР. Она построена вокруг SDMX: загрузка, хранение и обозреватель данных.
- **Fusion Metadata Registry** — реестр структур SDMX: справочников, описаний наборов и понятий. Его ведёт Банк международных расчётов (БМР). Приложение бесплатно по публичной лицензии БМР, сопутствующие инструменты открыты под Apache 2.0, выпуск 12.4.2 вышел 19 сентября 2026 года. На нём работает, например, реестр SDMX Евростата.

Всё остальное — собственные разработки служб, отсюда и 42% самописных витрин.

## Что отличает удобный каталог показателей

Шесть признаков, по которым видно, что статистика опубликована как данные, а не как сайт с графиками.

1. **Общие справочники.** Территории, отрасли, товары закодированы одними справочниками для всех показателей. Тогда любой ряд читается одной программой. У Евростата это общие справочники SDMX на все наборы.
2. **Массовая выгрузка.** Всю базу можно забрать без кликов по каждому показателю. FAOSTAT отдаёт архив на каждую тематическую базу и машиночитаемый перечень архивов. Евростат публикует опись всех наборов со ссылками на файл каждого в TSV, CSV и SDMX. У МОТ есть отдельная страница массовой выгрузки ILOSTAT.
3. **Общий поиск.** Один поиск находит и показатель в базе, и таблицу в сборнике, и архивную публикацию.
4. **Обычный портал открытых данных как канал.** Показатели выкладываются наборами на стандартной платформе с её API. Так делает Центральный банк Бразилии: его портал открытых данных работает на CKAN.
5. **Несколько форматов и код.** Не только Excel: CSV, SDMX, JSON-stat, форматы статистических пакетов, пример запроса на Python или R прямо на странице показателя.
6. **Техническая документация.** Описание API по OpenAPI, примеры запросов, Parquet для больших таблиц. Документация в виде веб-страниц с примерами, а не PDF-отчёта подрядчика.

Каталог, где есть только конструктор таблиц, не проходит по второму, пятому и шестому пунктам, даже если выглядит современно.

## Примеры

Хорошие порталы показателей устроены похоже: одна база и несколько входов для разных людей. Аналитику нужен график, программисту — API, тому, кто строит свою базу, — выгрузка целиком, а автору статьи — постоянная ссылка на ряд.

- [Портал данных Европейского центрального банка](https://data.ecb.europa.eu) обслуживает все эти аудитории сразу. У каждого ряда есть график и постоянный адрес вида `data.ecb.europa.eu/data/datasets/EXR/EXR.D.USD.EUR.SP00.A`, на который можно сослаться. Для программ есть API по стандарту SDMX 2.1, а каждый набор скачивается целиком. В 2024 году наборов было 108, все вместе они занимали 93 ГБ в CSV и 664 МБ после перевода в Parquet.
- [Портал данных БМР](https://data.bis.org) — образец работы с SDMX. Есть API, постоянная ссылка на ряд и раздел массовой выгрузки, где каждая тема скачивается одним архивом в CSV или SDMX.
- [Мексиканский INEGI](https://www.inegi.org.mx) собирает всё по одному обследованию на вкладках одной страницы: документацию с методикой и описанием в стандарте DDI, таблицы, микроданные, открытые данные и инструменты. Есть API банка индикаторов и раздел массовой выгрузки по территории, теме и году.
- [Статистика Канады](https://www150.statcan.gc.ca/n1/en/type/data) превратила сайт службы в каталог данных. В октябре 2026 года через её API доступно 8270 таблиц, из них около 5,1 тысячи действующих, остальные в архиве. Каждая таблица скачивается целиком в CSV или SDMX. К аналитическим текстам приложены таблицы из той же базы.
- [Статистика Хорватии](https://podaci.dzs.hr/en) справляется с раздробленностью единым каталогом. На странице темы в одном списке собраны оперативные выпуски, сборники, таблицы PC-Axis, базы краткосрочной статистики и слои геостатистики, метаданные которых ведутся в GeoNetwork. Пользователь не обязан знать, в какой системе лежит нужная таблица.
- [OpenDOSM](https://open.dosm.gov.my) — портал статистической службы Малайзии с открытым кодом. Каждый набор лежит в CSV и Parquet, на странице есть пример чтения на Python, для программ есть API. На той же платформе работает национальный портал data.gov.my.
- [OECD Data Explorer](https://data-explorer.oecd.org) — .Stat Suite.
- [Statbank Denmark](https://www.statbank.dk/) — PxWeb.
- [Браузер данных Евростата](https://ec.europa.eu/eurostat/databrowser/) — ряды с разрезами, не файлы по годам.
- [Our World in Data](https://ourworldindata.org) — витрина с собственной платформой, не национальная статистика.

Показатели и микроданные одной службы — два каталога. Почему их не склеивают в один самописный сайт, разобрано в [примере статистической службы](../06-choice/08-worked-examples.md).

## Где ломается

Таблица доступна только через конструктор: выгрузка есть, API нет. Методика показателя живёт в PDF, а не рядом с рядом. Число «наборов» раздувают, выкладывая один показатель отдельным файлом на каждый год.

Есть ловушка тоньше: выгрузка повторяет то, что показано на экране. В российской ЕМИСС (fedstat.ru) в 2022 году показатель открывался в «просмотре по умолчанию» — последние годы и несколько регионов, — и скачивался тоже только этот срез. Чтобы получить ряд целиком, нужно было вручную отметить все разрезы. Там же на семь тысяч показателей приходилось почти 700 справочников, многие из которых повторяли друг друга. У Евростата в то же время было 283 справочника на 10,5 тысячи наборов. Без общих справочников ряды разных ведомств не склеиваются.

К 2025 году к этим бедам добавилось устаревание. В июне 2025 года при сплошной выгрузке из ЕМИСС удалось скачать 6905 показателей из 8773 заявленных, и 41,8% из них не обновлялись с 2022 года. У некоторых ведомств ряды остановились гораздо раньше: у Россельхознадзора последнее обновление было в 2014 году. Независимый подсчёт проекта «Если быть точным» (август 2025 года) дал похожую картину: из 7280 доступных показателей актуальных и обновляемых около 3,7 тысячи.

Саму систему собираются закрыть. В мае 2025 года стало известно, что по приказу Минцифры и Росстата ЕМИСС выводится из эксплуатации до 31 декабря 2025 года. Текста приказа тогда не было ни на сайтах ведомств, ни на портале официального опубликования. Замена — государственная система «Цифровая аналитическая платформа», запуск которой с 2022 года переносили несколько раз; по данным «Если быть точным», переход отложили до января 2027 года. В ноябре 2025 года ЕМИСС ещё работала: по снимку веб-архива — 8875 показателей от 61 ведомства. В 2026 году сайт не открывается из-за рубежа, и проверить его состояние со стороны нельзя. Вывод для пользователя: ряд, который нужен надолго, скачивайте целиком и храните у себя. Как общественный архив сохранил ЕМИСС, рассказано в главе [об архивации](../09-practices/04-archiving.md).

Статистика разных уровней тоже может не сходиться в одном месте. У территориальных органов Росстата у каждого свой сайт со своим набором сборников, часть которых продаётся по подписке, и единого каталога этих публикаций нет (2024).

Тиражируемое ПО помогает, только если его обновлять. Статбанк Армении (statbank.armstat.am) долго работал на старой версии PxWeb на ASP.NET: стандартный API не отвечал, и чтобы забрать данные, приходилось писать отдельный парсер (ноябрь 2025 года). В октябре 2026 года там уже стоит PxWeb выпуска 2025 года, и стандартный API отвечает. Обновление вернуло данные в общие инструменты без новой разработки.

SDMX нужен для обмена с международными организациями, но внедрять его тяжело. По оценке 2026 года, активно внедряемых серверных продуктов всего три, и без консультантов их ставят редко. Поэтому за пределами национальных служб и международных организаций SDMX почти не встречается, как и более лёгкий JSON-stat. Небольшой службе разумно начать с массовой выгрузки в CSV или Parquet и документированного API, а точку SDMX добавить готовым продуктом, а не писать самой.

Новый портал может потерять то, что было у старого. В 2024 году портал данных МВФ давал наборы для массовой выгрузки. В новом data.imf.org, открытом весной 2025 года, появились каталог наборов, сквозной поиск, дашборды и новый SDMX API. Но в апреле 2025 года скачать всё сразу было нельзя, машиночитаемого перечня наборов не было, разметки Schema.org и DCAT тоже, на отдельный ряд нельзя было дать ссылку, а API требовал регистрации. В октябре 2026 года SDMX API МВФ отвечает без ключа, остальное стоит проверять заново.

## Чем отличается от соседей

От портала открытых данных единица публикации — показатель, а не файл. От каталога микроданных — агрегаты, а не записи о респондентах.
