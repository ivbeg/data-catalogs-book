# Экспорт цитирования

Люди ссылаются на данные, когда это занимает секунду. Если ссылку нужно собирать вручную из названия, года и адреса, большинство процитирует статью или не процитирует ничего.

Экспорт цитирования — это готовая ссылка на набор: строка на странице и файл для менеджера библиографии.

## Из чего состоит ссылка

Практический минимум, на котором сошлись инициативы по цитированию данных (FORCE11, 2014):

- авторы;
- год;
- название;
- версия, если данные версионируются;
- издатель или репозиторий;
- постоянный идентификатор, лучше DOI.

Без автора и года кнопка «Цитировать» выдаёт пустышку. Сначала в описании должны быть эти поля. См. [полноту метаданных](./03-metadata-depth.md) и [идентификаторы](./06-identifiers-and-doi.md).

## Какие бывают выгрузки

- Строка на странице, чтобы скопировать в текст.
- Файл для программы: BibTeX, RIS, EndNote XML, CSL-JSON.
- Выбор стиля (APA, ГОСТ и другие) через стили CSL.
- Ссылка по DOI без участия каталога: DataCite и Crossref отдают её по запросу, если DOI зарегистрирован.

Для репозитория на GitHub ту же роль играет файл `CITATION.cff`: площадка показывает кнопку «сослаться на репозиторий».

## Когда это нужно

Обязательно для научного репозитория: цитирование — часть его задачи.

Желательно везде, где данными пользуются в исследованиях и аналитике, включая портал открытых данных при университете или министерстве.

Не нужно, если данные служебные и на них не ссылаются: оперативная витрина, внутренний слой карты. Даже там постоянный адрес полезен, а генератор BibTeX — нет.

## Как это сделано в платформах

| Платформа | Где |
|-----------|-----|
| Dataverse | в ядре: строка ссылки и выгрузка EndNote, RIS, BibTeX и стилей CSL, на уровне набора и файла |
| InvenioRDM, Zenodo, Figshare | в ядре: строка и несколько форматов |
| DSpace | в ядре есть выгрузка библиографических форматов; набор зависит от версии и настройки |
| CKAN, OpenDataSoft, Socrata, ArcGIS Hub | нет. Поддерживаемого расширения книга не называет; на CKAN остаётся правка шаблона |
| GitHub | файл `CITATION.cff` в репозитории, не платформа каталога |

Dataverse прямо называет форматы цитирования штатной функцией: EndNote XML, RIS, BibTeX и стили CSL ([описание возможностей](https://guides.dataverse.org/en/latest/admin/features.html)).

Если DOI есть, а кнопки на сайте нет, ссылку всё равно можно получить у DataCite:

```bash
curl -LH "Accept: text/x-bibliography; style=apa" https://doi.org/10.5281/zenodo.1234567
```

Это не заменяет кнопку на странице набора. До неё дойдёт только тот, кто уже знает про этот приём.

## Как проверить живой портал

- На странице набора есть блок «Как цитировать» с авторами, годом и идентификатором.
- Скачивается BibTeX или RIS, и в файле тот же идентификатор, что на странице.
- Для двух версий одного набора ссылки различаются номером версии.
