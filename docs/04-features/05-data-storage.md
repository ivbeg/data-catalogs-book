# Внутреннее хранилище

Каталог может хранить сами файлы или только описывать их и давать ссылку туда, где файл лежит. Это развилка, а не мелочь оформления.

Если файл лежит в каталоге, он доступен, пока жив каталог. Если каталог только ссылается на сайт ведомства, ссылка пропадёт вместе с переделкой того сайта. Зато своё хранилище — это место на диске, резервные копии и плата за скачивание.

Риск пропажи не теоретический. Тот же вопрос в 2026 году разбирала Исследовательская служба Конгресса США: data.gov по закону — единая точка входа, которая ведёт на данные на сайтах ведомств, и в отчёте прямо поставлен вопрос, не должен ли он стать хранилищем, чтобы доступ к данным не пропадал вместе с сайтом ведомства. При полной выгрузке data.gov.uk в 2023 году около 10% ссылок на файлы не открывались, а к 2026 году, по оценке самой службы, нерабочих ссылок стало больше четверти. Портал собирал ссылки на муниципальные сайты, а те меняли платформу или домен. Сохранить файлы, которые лежат у самого каталога, тоже проще: архив снимают с одного сайта, а не с сотни.

## Четыре варианта

**Только ссылки.** Каталог — указатель. Так устроены многие геопорталы: слой живёт в картографическом сервере, каталог хранит адрес сервиса. Так же устроен агрегатор: данные остаются у источника.

**Файлы в каталоге.** Публикатор загружает CSV, архив, снимок. Хранилище может быть диском сервера или облачным баком (S3 и аналоги). Для научного репозитория это обычный режим: статья ссылается на файл, который нельзя «потерять на соседнем сайте».

**Таблица в базе каталога.** Файл CSV не только лежит, но и загружен в базу. Тогда можно посмотреть первые строки в браузере и запросить данные через API, не скачивая всё. Это удобно для больших и часто обновляемых таблиц и бессмысленно для карты в PDF.

**Смесь.** Часть наборов хранится, часть ссылается наружу. Так бывает на порталах открытых данных: реестр выгружается файлом в каталог, а датчики остаются на сервере ведомства.

## Когда что выбирать

Своё хранилище нужно, если у публикаторов нет надёжного места для файлов или если на файл будут ссылаться годами. Это случай научного репозитория и случай организации, у которой данные сегодня лежат «на общем диске».

Ссылок достаточно, если источник и так устойчив: национальная статистическая база, картографический сервер, который живёт своей жизнью. Дублировать его в каталог дорого и быстро приводит к двум расходящимся копиям.

API к таблицам нужен, когда таблицей пользуются программы и люди хотят фильтровать её в браузере. Для квартального отчёта из одного файла хватает скачивания.

Хранилище — это обязанность. Кто-то следит за местом, копиями и тем, что старый файл не исчез в день, когда на него сослались.

## Как это сделано в платформах

Пометки — ядро, расширение, нет, не проверено, как в [сводной таблице](../12-appendices/03-platform-tables.md).

| Платформа | Файлы у себя | Ссылки наружу | API к таблицам |
|-----------|--------------|---------------|----------------|
| CKAN | ядро (FileStore) | ядро | ядро (DataStore); заливка CSV — расширение XLoader, CKAN 2.10–2.12 |
| Dataverse, InvenioRDM, DSpace | ядро | ядро (расчёт всё равно на файлы) | ядро (у Dataverse табличные файлы разбираются) |
| OpenDataSoft, Socrata | ядро | не проверено | ядро |
| ArcGIS Hub | ядро | ядро (слой может жить на сервере ArcGIS) | ядро (сервисы ArcGIS) |
| GeoNetwork | ядро (чаще ссылка на сервис) | ядро | нет |
| PxWeb, .Stat | нет | нет | ядро (SDMX и собственный API) |
| Статический сайт, Git | файлы рядом со страницами или по ссылке | как решите | нет, пока сами не сделаете |

У CKAN облачное хранилище вместо локального диска подключается отдельной настройкой или расширением. Это стоит заложить до запуска: перенос уже загруженных файлов больнее, чем выбор хранилища в первый день.

## Как проверить живой портал

Откройте набор и нажмите «Скачать». Посмотрите адрес файла.

- Домен совпадает с порталом или это знакомое облачное хранилище портала — файл лежит «у каталога».
- Домен другой — это ссылка на источник. Проверьте несколько таких ссылок: хотя бы часть обычно уже не открывается.
- На странице есть таблица с фильтром и отдельный адрес API для этих строк — включён доступ к содержимому, а не только к файлу.

Полезно посчитать долю внешних ссылок, которые отвечают ошибкой. Это прямая мера того, стоит ли переносить файлы к себе.
