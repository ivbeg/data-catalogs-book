# Стабильные адреса для ссылок

Постоянный адрес книги — [datacatalogs.begtin.tech](https://datacatalogs.begtin.tech/). На главы и разделы можно ссылаться извне: их адреса не меняются молча.

## Адреса книги

| Версия | Сайт | PDF |
|--------|------|-----|
| Русская | [datacatalogs.begtin.tech](https://datacatalogs.begtin.tech/) | [data-catalogs-book.pdf](https://datacatalogs.begtin.tech/data-catalogs-book.pdf) |
| Английская | [datacatalogs.begtin.tech/en/](https://datacatalogs.begtin.tech/en/) | [data-catalogs-book-en.pdf](https://datacatalogs.begtin.tech/data-catalogs-book-en.pdf) |

Адрес главы на английском — тот же путь с приставкой `/en/`: например, `https://datacatalogs.begtin.tech/types/classification/` и `https://datacatalogs.begtin.tech/en/types/classification/`. Полный адрес главы — домен и путь со слэшем в конце.

Прежний адрес книги `ivbeg.github.io/data-catalogs-book/` перенаправляет на новый домен вместе с путём главы, поэтому старые ссылки продолжают работать. Как сослаться на книгу целиком, сказано в разделе [«Об издании»](../index.md#об-издании).

## Как адреса остаются стабильными

Путь главы не меняют молча. Если главу переименуют, со старого адреса настраивают перенаправление. Старые пути про API и идентификаторы уже ведут на новые главы.

Список путей для базы знаний реестра ведут вместе с сайтом, отдельно от текста для читателя.
