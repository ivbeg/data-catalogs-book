# Стабильные адреса для ссылок

Сайт ещё не опубликован по постоянному домену: в настройках сборки стоит адрес-заглушка. Пока домен не выбран, на главы извне не ссылаются.

Когда домен появится, путь главы не меняют молча. Если главу переименуют, со старого адреса настраивают перенаправление. Старые пути про API и идентификаторы уже ведут на новые главы.

Список путей для базы знаний реестра ведут вместе с сайтом, отдельно от текста для читателя.
