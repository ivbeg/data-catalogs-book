# Чек-листы

Короткие списки живут в главах, рядом с объяснением. Здесь они собраны в рабочем виде: их можно распечатать или скопировать в задачу. У каждого пункта ссылка на главу, где написано, зачем он нужен.

Два длинных списка остаются в своих главах, потому что без пояснений их не заполнить:

- [Требования к каталогу и сравнение платформ](../06-choice/07-requirements-checklist.md) — что писать в задании и что из этого обязательно не всем.
- [Самоаудит](../10-quality/04-self-audit.md) — как за один проход оценить свой каталог и что записать в итог.

## Проверка живого портала

Этот список подходит и для своего каталога, и для чужого, который вы рассматриваете как образец или как источник для сбора. На него уходит около получаса.

**Находимость и выгрузка**

- [ ] На странице набора есть блок `application/ld+json` с типом Dataset — [экспорт метаданных](../04-features/02-metadata-export.md).
- [ ] Отвечает карта сайта `sitemap.xml` — [API и массовая выгрузка](../04-features/04-access-interfaces.md).
- [ ] Есть файл со всеми описаниями (`data.json`, `catalog.rdf`, `catalog.ttl`), и он открывается без входа.
- [ ] Число наборов в выгрузке совпадает с числом в поиске на сайте.
- [ ] Выгрузка проходит валидатор нужного профиля: DCAT-AP, INSPIRE или DataCite — [метрики качества](../10-quality/02-metrics.md).
- [ ] Для геопортала отвечает CSW или OGC API Records, для научного репозитория — OAI-PMH.

**Описания**

- [ ] У десяти случайных наборов, не самых свежих, заполнены лицензия, издатель, дата обновления, период и территория — [полнота метаданных](../04-features/03-metadata-depth.md).
- [ ] Самое частое значение периода, территории и частоты обновления — не заглушка вроде «1900–2099» или «вся страна» у наборов разных организаций — [проверка на выборке](../04-features/03-metadata-depth.md#две-проверки-на-выборке).
- [ ] Описание не повторяет название и длиннее 50 символов: короче не примет разметка для Google.
- [ ] Лицензию ищут там, где её хранит схема: в DCAT-AP — у файлов, а не у набора.
- [ ] У табличных наборов есть словарь полей, и типы колонок совпадают с содержимым.
- [ ] Свои поля и плагины схем (ckanext-scheming, ckanext-validation, профили GeoNetwork) проверены по репозиторию и ветке под текущую версию ядра.

**Содержимое**

- [ ] Большинство наборов — не справки на одну-две строки, а общий объём данных сопоставим с главными источниками темы — [проверка по существу](../10-quality/04-self-audit.md#проверка-по-существу).
- [ ] «Обновлённые» наборы действительно изменились: в файле новые периоды, а не только новая дата в карточке.
- [ ] У CSV указаны или однозначны кодировка и разделитель — [антипаттерны](../09-practices/02-anti-patterns.md).

**Файлы и адреса**

- [ ] Ссылки «Скачать» открываются. Посчитайте долю внешних ссылок, которые отвечают ошибкой, — [внутреннее хранилище](../04-features/05-data-storage.md).
- [ ] Адрес страницы набора не меняется при правке описания — [идентификаторы](../04-features/06-identifiers-and-doi.md).
- [ ] Если обещан DOI, `https://doi.org/…` ведёт на страницу набора.
- [ ] Если портал переезжал, старые адреса перенаправляют, а не отвечают «не найдено».

**Цитирование и доступ**

- [ ] Есть блок «Как цитировать», скачивается BibTeX или RIS с тем же идентификатором — [экспорт цитирования](../04-features/07-citation.md).
- [ ] У набора видна организация и контакт — [доступ, роли и процессы](../04-features/08-access-control-and-workflow.md).
- [ ] Описания закрытых наборов видны без входа, скачивание — нет.

Сетевую часть можно проверить одним скриптом. Подставьте адрес портала:

```bash
PORTAL=https://portal.example
for path in sitemap.xml data.json catalog.rdf catalog.ttl \
            "api/3/action/package_search?rows=1" \
            "oai?verb=Identify" \
            "csw?service=CSW&request=GetCapabilities"; do
  code=$(curl -s -o /dev/null -w "%{http_code}" -L --max-time 20 "$PORTAL/$path")
  echo "$code  $path"
done
```

Ответ `200` по адресу, который подходит к типу каталога, — хороший знак. Ответ `401`, `403` или страница входа значит, что машинного доступа нет, даже если он обещан. Адреса для CKAN, OAI-PMH и CSW подходят не всем платформам: отсутствие ответа по чужому типу — не ошибка.

## Каталог показателей

Подробно — в главе [о каталогах показателей](../03-types/05-indicator-catalogs.md#что-отличает-удобный-каталог-показателей).

- [ ] Территории, отрасли и другие разрезы закодированы общими справочниками, справочники скачиваются.
- [ ] Всю базу можно забрать целиком: архивом или файлом на показатель плюс перечень файлов.
- [ ] Выгрузка из конструктора отдаёт весь ряд, а не только срез, показанный по умолчанию.
- [ ] Есть API, у каждого показателя — постоянный адрес запроса.
- [ ] Кроме Excel есть CSV и SDMX или JSON-stat.
- [ ] Методика и единица измерения лежат рядом с рядом, а не только в PDF.
- [ ] API описан по OpenAPI или хотя бы веб-страницей с примерами запросов.

## Перед установкой расширения

Подробно — в главе [об экосистемах расширений](../05-platforms/02-extension-ecosystems.md).

- [ ] Понятно, кто выпускает расширение: организация, а не один человек без ответа два года.
- [ ] Ваша версия ядра названа в таблице совместимости, тестах или ветках. «Работало у соседей» не считается.
- [ ] Последний выпуск и исправления свежие, ошибки про новую версию ядра не висят без ответа.
- [ ] Установка описана в документации расширения, а не только в чужом блоге.
- [ ] Есть файл лицензии, и она разрешает то, что вам нужно.
- [ ] В карточке решения записано, что делать, если расширение перестанут поддерживать — [как обосновать решение](../06-choice/04-justifying-decisions.md).

## Перед покупкой или установкой платформы

Подробно — в главах [о развёртывании и сопровождении](../04-features/09-deployment-and-operations.md) и [о цене ухода](../06-choice/05-build-or-buy.md).

- [ ] Есть официальный контейнер и короткая инструкция обновления.
- [ ] Известно, сколько последних версий поддерживается и как часто они выходят.
- [ ] Посчитано, сколько расширений нужно для обязательных функций и кто их выпускает.
- [ ] Названо, кто будет дежурить через два года: своя ставка, подрядчик или поставщик сервиса.
- [ ] Проверено, что все описания и файлы можно выгрузить целиком, — иначе уйти с платформы будет дорого.
- [ ] Пилот прошёл на десяти настоящих наборах, а не на демонстрационных.

## Перед тем как назвать набор опубликованным

Подробно — в главе [о процессе публикации](../07-publishing/01-publishing-process.md).

- [ ] У набора постоянный адрес.
- [ ] Лицензия указана на наборе и попадает в выгрузку описаний.
- [ ] Файл или сервис открывается, или честно сказано, почему он недоступен и как его запросить.
- [ ] Указаны дата обновления и периодичность.
- [ ] Описание попало в общую выгрузку и видно верхнему порталу.
- [ ] Черновик не попал в поиск до публикации.

## Перед выключением каталога

Подробно — в главах [о жизненном цикле](../09-practices/03-lifecycle.md) и [об архивации](../09-practices/04-archiving.md).

- [ ] О закрытии объявлено заранее, за месяцы, а не за дни; на переходный срок каталог работает только на чтение.
- [ ] Данные переданы в другой каталог или архив, либо явно сказано, что они сняты с публикации.
- [ ] Старые адреса либо перенаправляют, либо хотя бы год отвечают, куда переехал набор.
- [ ] Снимок описаний сохранён: выгрузка через API или файл DCAT, а не только страницы сайта.
- [ ] Файлы, которые лежат только в этом каталоге, сохранены вместе с адресами, откуда они взяты.
- [ ] Проверено, что сайт есть в Интернет-архиве или национальном веб-архиве и что архив до него доходит, в том числе из-за рубежа.
- [ ] Верхний портал и реестры, где каталог был зарегистрирован, уведомлены.

## Минимум публикации без портала

Подробно — в главе [о том, как сделать публикацию находимой](../08-beyond-portals/05-making-it-findable.md).

- [ ] Страница с постоянным адресом и понятным описанием.
- [ ] Лицензия рядом с данными.
- [ ] Разметка schema.org/Dataset, чтобы страницу нашли человек и поисковик.
- [ ] Файл в том профиле, который забирает верхний портал, если набор должен попасть в федерацию.
- [ ] `datapackage.json`, чтобы по файлу было понятно, какая это таблица и что в колонках.
- [ ] Дата обновления и контакт.

Готовые заготовки файлов — README, `datapackage.json`, `CITATION.cff` и разметка schema.org — лежат в [шаблонах](pathname:///templates/README.md).
